# Teams 알림 연결 방안

메일만 사용할 필요는 없습니다. Teams의 **Workflows** 앱에서 `When a Teams webhook request is received` 트리거를 만들고, 승인 담당 채널에 알림을 게시할 수 있습니다. 기존 Office 365 Connector 기반 Incoming Webhook은 공식 문서 기준 2026년 5월 종료되었으므로 새 연결은 Workflows로 구성합니다.

외부 기관은 Teams를 사용하지 않으므로 Teams 가입을 요구하지 않습니다. 내부 승인자에게는 Teams 채널 알림을 보내고, 외부 기관 신청자에게는 기관 업무 화면의 처리 결과와 선택적으로 이메일 알림을 제공합니다. 외부 신청자 메일을 자동 발송하려면 SMTP 또는 메일 API 설정과 실패 재시도 처리가 별도로 필요합니다.

권장 알림은 `가입 신청 접수`, `강사 변경 신청 접수`, `승인·반려 완료`입니다. 담당자 채널에는 신청 종류·대기 건수·기관 업무 화면 링크를 보내고, 승인과 개인정보 확인은 로그인한 웹 화면에서 처리합니다. 신청자 개인 알림은 UPN 매핑과 Teams/Graph 권한 또는 메일 전송 구성이 추가로 필요합니다. 채널 웹훅만으로 특정 신청자에게 개인 메시지가 전달되는 것은 아닙니다.

실제 연결 시 필요한 항목:

1. 알림을 받을 Teams 팀·채널과 Workflows를 만들 수 있는 담당자.
2. 담당자가 만든 웹훅 URL을 서버의 보호된 환경 설정에 등록. URL은 인증 수단이므로 Git이나 채팅에 기록하지 않음.
3. 워크플로 소유자 변경에 대비한 공동 소유자 지정.
4. DB에 신청·승인 결과가 커밋된 뒤 outbox 작업으로 전송. 실패 시 재시도하고, 중복 이벤트는 식별자로 제거. Teams 오류 때문에 신청·승인 저장이 실패하지 않게 구성.

이번 수정에는 자동 전송을 활성화하지 않았습니다. 채널과 인증 방식을 정한 뒤 연결하고, 허가된 테스트 메시지로 확인해야 합니다.
