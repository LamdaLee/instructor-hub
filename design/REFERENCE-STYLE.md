# 참고 이미지 기반 구조 개편 (v5)

WECANDEO의 작은 둥근 헤더·중앙 정렬·민트/하늘색 비주얼 카드와 littly의 높이가 다른 3열 컬러 카드를 참고해 화면 구조를 다시 구성했습니다.

- 중앙 타이틀 아래 날짜와 전체/지역 시간표 바로가기.
- 엇갈린 3열 카드에 7개 반의 수업·강사·기관·배정 상태·매니저·강의장·교재 링크 표시.
- 트랙별 자체 SVG 일러스트와 민트·하늘색·크림·라일락 등의 카드색.
- 포스트잇 공지를 수업 카드 사이에 배치. 모바일은 가로 스크롤 공지와 한 열 카드.
- 시간표는 지역·트랙 행 × 날짜·요일 열과 기간 조회. 중립색 셀에 기관 배지만 색상 사용.
- 감성 문구나 통계판 없이 과정 이름과 관리 정보 사용.

`mockup/index.html`은 자체 포함 최신 파일입니다. `mockup/reference-portal.css`에서 새 배치를 정의합니다. 이전안은 `mockup/versions/v4.html`에 보존합니다. 참고 이미지의 사진·로고·캐릭터는 사용하지 않았습니다.

## 검증

`node design/mockup/build.mjs` 후 `node design/mockup/verify.mjs`로 Chromium 검증을 실행합니다. 3열 배치, 공개 조회·연락처, 공지 CRUD·변경 기록, 과정 추가, 엑셀 붙여넣기, 셀 메모, 시간표 필터, 밝은/어두운 테마, 375px, 키보드와 모션 줄이기를 확인합니다.

Lucian #039 배정 상태 탭과 #070 저장 알림을 사용합니다. 강사 상세는 최신 요청에 따라 자체 중앙 모달로 교체했습니다. 원본과 크기 조정 내역은 `REDESIGN.md`에 기록되어 있습니다. 가상 데이터 목업이며 운영 DB·서비스에는 적용하지 않았습니다.
