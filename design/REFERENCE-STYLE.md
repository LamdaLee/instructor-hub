# 참고 이미지 반영 선택안

사용자가 제공한 WECANDEO·littly 화면의 색감·카드·여백을 참고했습니다. 사용자가 선택한 “민트·하늘색과 카드 스타일”을 기본 목업으로 적용하고, 기존 운영용 화면 구성과 기능은 유지했습니다.

- `mockup/index.html`: 선택된 민트·하늘색 기본 목업.
- `mockup/index-original.html`: 이전 관리용 목업.
- `mockup/index-mint.html`: 참고 이미지의 민트·하늘색과 흰 카드 스타일을 적용한 비교안.
- `mockup/mint-reference.css`: 비교안 전용 색상·배치 조정. 기존 CSS와 Lucian 원본은 유지.
- `mockup/screenshots/mint/`: 비교안의 데스크톱·모바일 캡처.

## 반영한 부분

- 밝은 바탕과 옅은 민트/하늘색 그라데이션.
- 둥근 흰 카드, 지역별 배경 영역, 충분한 카드 간격.
- 민트색 선택 상태와 버튼, 흰색의 둥근 상단 바.
- LG전자 K-뉴딜 아카데미 타이틀과 기존 기관 색 구분.
- 공지사항은 포스트잇 형태를 유지하고, 수업 카드는 관리 정보만 표시.
- 전체 시간표는 기관별 셀 배경색·격자·지역 구분선을 유지.

수업 현황·공지·날짜/반 시간표·지역/기수/트랙/기관 필터·관리자 전용 편집 기능을 유지합니다. 큰 홍보용 배너나 통계판, 감성적인 설명 문구는 추가하지 않습니다. 참고 이미지의 실제 사진·로고·캐릭터는 사용하지 않습니다.

## 검증

```bash
node design/mockup/build.mjs
node design/mockup/verify.mjs --mint
```

공개 화면, 공지 등록·수정·삭제·변경 기록, 강사 정보, 과정 추가, 엑셀 붙여 넣기, 셀 메모, 자료실 안내와 밝은/어두운 테마·키보드·모션 줄이기·375px 모바일 검증을 수행합니다.

비교안에서도 Lucian #039 배정 상태 탭, #070 저장 알림, #273 강사 상세 패널을 재사용합니다. 색은 프로젝트 토큰으로 연결하며 출처·원본 형태·모션은 보존합니다. 원본과 크기/가독성 조정 내역은 `REDESIGN.md`에 기록되어 있습니다.

가상 데이터 목업입니다. 운영 화면·DB에는 적용하지 않았습니다.
