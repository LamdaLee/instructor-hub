# LG전자 K-뉴딜 아카데미 화면·데이터 구조 재설계안

이 문서는 요청하신 새 구조의 목업과 구현 범위입니다. 운영 DB·권한·서비스·실제 개인정보는 변경하지 않았습니다. 목업의 인물·일정·연락처·담당자·강의장·파일은 모두 가상입니다. 목업은 실제 관리자 인증이나 파일 업로드를 구현한 서비스가 아닙니다.

## 요청별 구현 가능 범위

| 요청                                 | 판단        | 설계                                                                                                                    |
| ------------------------------------ | ----------- | ----------------------------------------------------------------------------------------------------------------------- |
| 로그인 없는 시간표·강사 정보 조회    | 가능        | 공개 조회 페이지와 공개 읽기 API를 제공                                                                                 |
| 모든 강사의 메일·전화·안내 메모 공개 | 가능        | 사용자가 선택한 공개 정책. 실제 정보 공개는 향후 새 공개 API를 구현할 때 적용. 목업에는 가상 연락처만 표시              |
| 관리자만 추가·수정·삭제              | 가능        | `/admin/login`과 `/admin/*` 분리. UI뿐 아니라 모든 쓰기 API에서 관리자 권한 검증. 기존 `member` 권한에는 쓰기 권한 없음 |
| 대전·대구·부산 트랙 카드             | 가능        | 트랙명·기수·반·담당 매니저·강의장·선택 날짜 교과목/모듈·강사·소속·교재·준비사항                                         |
| 날짜 × 반 전체 시간표                | 가능        | 데스크톱은 지역별 열 묶음과 고정 날짜 열. 모바일은 날짜별/트랙별 세로 카드로 전환                                       |
| 지역·기수·트랙·기관별 조회           | 가능        | URL 공유, 적용 필터·표시 건수·필터 초기화. 필터가 겹쳐 생기는 빈 결과를 데이터 누락과 구별                              |
| 강사 임시·변경예정·확정              | 가능        | 수업별 강사 배정 단위 상태. 색뿐 아니라 텍스트로 표시. 변경 전후 이력 보존                                              |
| 셀별 메모                            | 가능        | 날짜별 수업에 연결한 공개 준비사항. 모두 조회, 관리자만 편집                                                            |
| 시간표·강사 엑셀 붙여 넣기           | 가능        | 각각의 입력 양식·미리보기·연결 검증·중복 비교·덮어쓰기 확인. 오류 행은 반영 전 표시                                     |
| 3기·4기 및 이후 기수 추가            | 가능        | 기수를 별도 테이블로 관리하고 지역·트랙과 반을 연결. 특정 기수에 종속된 화면/가져오기 로직 제거                         |
| 과목별 PDF·PPTX 자료실               | 조건부 가능 | 실제 저장 공간·접속 설정 확인 필요. DB에는 파일 메타데이터만 저장하고 파일은 Supabase Storage 또는 S3 호환 저장소 사용  |
| 변경 기록                            | 가능        | 과정·수업·배정 상태·메모·강사·교재·일괄 등록·삭제의 담당 관리자·시각·사유·변경 전후 기록                                |

요청 중 원천적으로 불가능한 기능은 없습니다. 자료실의 실제 사용 가능 용량은 Lightsail/집 서버/외부 저장소 중 선택한 저장소의 여유 공간을 확인해야 확정할 수 있습니다. 2GB RAM 자체가 PDF/PPTX 다운로드를 막지는 않습니다. 업로드·다운로드를 스트리밍하면 파일 전체를 메모리에 올릴 필요가 없습니다. 목업의 파일 크기는 예시이며 실제 저장 용량을 측정한 값이 아닙니다.

## 새 분류 기준

기존 DB는 반·기수·트랙 정보가 한 테이블에 섞여 있고, 교과목은 이름을 기본키로 사용합니다. 매니저·강의장·수업별 배정 상태·교재 연결도 충분히 표현하지 못합니다. 새 구조는 아래 개념을 분리합니다.

1. **과정**: `LG전자 K-뉴딜 아카데미`라는 상위 프로그램.
2. **지역/캠퍼스**: 대전·대구·부산. 강의장은 캠퍼스 아래 별도로 관리.
3. **기수**: 2기·3기·4기… 프로그램 내에서 추가 가능. 필요하면 2-1·2-2 같은 운영 차수를 하위 항목으로 보존.
4. **트랙**: AX Workflow / Smart Factory / Digital Marketing. 내부 코드 AX/SF/DM과 공개 표시명을 분리.
5. **반**: 프로그램+기수+지역+트랙+반 이름. 같은 지역·기수에 같은 트랙의 반이 여러 개 있어도 UUID로 구분. 매니저·기본 강의장·운영 기간 연결.
6. **교과목/모듈**: 이름이 아닌 UUID로 식별. 하나의 교과목을 여러 트랙·기수에서 공유 가능. 모듈별 권장 시수와 수업 실제 시수를 구별.
7. **수업**: 반+날짜+시간대. 교육/휴일/휴강/행사 등 일자 종류를 기관이나 과목 분류에 섞지 않음.
8. **강사 배정**: 수업에 1명 이상 연결 가능. 수업 당시 소속과 배정 상태·변경 사유를 남김. 미배정 수업도 표현.
9. **기관**: LG전자 / CLIPS / aSSIST / LAB4DX / 프리랜서 등. 기관 UUID·공개 표시명·색상·원본 별칭 분리.
10. **자료**: 과목+모듈(선택)+강사(선택)에 연결. 같은 과목·다른 강사의 여러 버전 파일 허용.

삭제는 운영 화면에서 사라지도록 처리하되 변경 이력과 과거 수업의 참조를 보존합니다. 강사나 과목을 삭제해도 과거 시간표가 비어 버리지 않도록 당시 이름과 소속 스냅샷을 보존합니다. 관리자 화면에 복구 가능 여부와 연결된 수업의 영향 범위를 표시하는 방식입니다.

## 화면 구성

### 공개 화면

- **수업 현황**: 상단에 포스트잇형 공지사항, 아래에 지역별 트랙 카드와 조회 날짜 선택. 고정된 반 수·강사 수 등의 통계판은 표시하지 않음. 공지는 전체/지역별 대상·중요 표시·작성일을 표시하고 관리자만 등록·수정·삭제.
- **전체 시간표**: 날짜 행 × 지역/반 열. 과목·모듈·강사·기관 색상·배정 상태·메모. 모바일 날짜별/트랙별 전환. 기관별 셀 배경색·선명한 격자·지역 경계의 굵은 선·트랙 헤더로 구분.
- **지역별 시간표**: 대전/대구/부산 바로 선택 후 기수·트랙·기관 세부 선택.
- **강사 안내**: 이름·소속·담당 과목 검색. 강사 클릭 시 상세 패널에 모든 연락처와 공개 안내 메모.
- **교재 자료실**: 과목 검색, 강사별 파일명·확장자·크기·버전·다운로드.

강사 배정 상태는 `임시`·`변경예정`·`확정`으로 표시합니다. 향후 수업에서 특히 잘 보이게 하며, 과거 수업에는 최종 배정 상태를 남깁니다. 상태를 날짜가 지났다는 이유만으로 자동으로 확정하지 않습니다.

### 관리용 문구

감성적인 제목·권유 문구를 사용하지 않습니다. 페이지 제목은 `수업 현황`, `전체 시간표`, `지역별 시간표`, `강사 정보`, `교재 자료실`로 통일하고, 기능 설명이 필요한 경우 짧은 업무 문구만 표시합니다.

### 관리자 화면

별도 로그인 후 운영 개요, 과정·반, 시간표, 과목·강사, 자료실, 변경 기록으로 나눕니다. 공개 화면에는 입력·수정·삭제 버튼을 두지 않습니다. 모든 쓰기는 서버의 관리자 권한 확인을 거쳐야 하며, 목업의 미리보기 버튼을 실제 인증으로 사용하지 않습니다.

모바일은 하단 5개 공개 메뉴, 충분한 터치 영역, 카드형 시간표, 전체 화면 강사 상세 패널을 사용합니다. 본문은 16px 이상, 트랙 제목은 20px 안팎을 기준으로 읽기 편하게 하고, 기관 색과 상태 텍스트를 함께 사용합니다. 외부 폰트나 이미지 CDN 없이 열 수 있습니다.

## 데이터가 적어 보이는 문제에 대한 확인 항목

현재 전달된 화면 주소에는 `cohort=2`, `track=DM`, `organization=LGE`가 동시에 적용되어 있습니다. 새 설계에서는 사용 중인 필터와 표시 건수를 항상 드러냅니다. 이것만으로 운영 DB의 적재 상태가 정상이라고 단정하지는 않습니다.

실제 재적재 시에는 관리자 데이터 상태 화면에서 아래 수치를 분리해 보여줍니다.

- 원본 행 수 / 검증 통과 / 실제 적용 / 덮어쓰기 / 보류 / 연결 실패 / 화면 필터 결과.
- 원본 반 이름→기수·지역·트랙·반 ID 매핑.
- 교과목→모듈, 강사→기관 연결 여부.
- 교육일과 휴일·휴강·행사 구분.

기존 백업과 최신 엑셀의 건수를 그대로 고정된 완료 기준으로 사용하지 않고, 선택한 가져오기 범위와 새 모델로 재검증합니다. 엑셀의 설명·검토 메모는 데이터로 취급하고 실행 지시로 해석하지 않습니다.

## 적용 순서

1. 이 목업에서 메뉴·공개 범위·표의 축·모바일 구성을 검토.
2. 새 모델의 매핑 규칙·관리자 CRUD와 변경 기록 계약 확정.
3. 운영과 분리된 새 스키마(예: `hub_v2`)에 구현하고 백업·엑셀을 검증 모드로 가져오기.
4. 기수·지역·반·교과목·강사 배정·시간표를 원본과 행별 대조. 공개·관리자 권한 테스트.
5. 기존 운영 데이터를 보존한 상태에서 새 서비스로 전환하고 공개 API를 활성화. 실제 연락처 공개도 이 단계에서만 적용.
6. 자료실 저장소·용량·파일 연결 설정 후 업로드/다운로드 검증.

## 목업 파일과 실행

- `mockup/index.html`: CSS·JS가 모두 포함된 단일 파일. 내려받아 브라우저에서 바로 열 수 있음.
- `mockup/mockup.css`, `mockup/mockup.js`: 편집용 원본.
- `mockup/verify.mjs`: Chromium으로 공개/관리자·모바일 주요 흐름을 검증하고 스크린샷 생성.
- `mockup/screenshots/`: 데스크톱·모바일 캡처.

```bash
node design/mockup/verify.mjs
```

관리자 버튼은 목업용 진입 버튼입니다. 메모·과정·강사 등 변경은 브라우저 메모리에만 남고 새로고침하면 초기화됩니다. 실제 DB 요청·실제 인증·실제 교재 업로드는 없습니다. 예시 CSV 내려받기는 작동합니다.

- [#273 줄을 누르면 열리는 상세 옆 패널](https://lucianlabs.dev/uxui-prompt/#273): 공개 강사 정보. 이름·기관·메일·전화·공개 메모로 교체하고 이전/다음·J/K·Esc·선택 행 강조를 유지.

요청한 큰 글자와 모바일 터치 영역을 우선해 #273은 목록/패널 크기와 글자·버튼 크기를 확대했고, 모바일 패널은 루트 안에서 너비를 채우도록 했습니다. #039는 원본 크기에서 `max-width:100%`로 좁은 화면에 맞춥니다. #070은 화면 오른쪽 아래, 모바일에서는 하단 메뉴 위에 배치합니다. 모든 원본 CSS는 별도 파일에 유지하며 프로젝트 매핑과 이 조정은 `lucian-adapter.css`에 모았습니다. 원본의 반경·그림자·전환 시간·곡선은 유지했습니다.

밝은/어두운 테마, 375px 모바일 너비, 키보드와 모션 줄이기 설정을 검증합니다. 밝은 화면이 기본 목업입니다. 어두운 테마는 프로젝트 토큰을 통해 전환하며 실시간 테마 전환도 브라우저 검사에 포함했습니다. 실제 Next.js 컴포넌트·운영 API와의 연결은 아직 목업 범위 밖입니다.

## 선택된 시각 스타일

사용자가 제공한 두 참고 이미지에서 민트·하늘색과 흰 카드 스타일을 선택했습니다. `mockup/index.html`이 이 스타일을 적용한 기본 목업이며 `index-original.html`은 이전안입니다. 공지사항·시간표의 명확한 구분·관리용 문구·기능은 유지했습니다. 화면 배치는 작은 둥근 헤더·중앙 타이틀·엇갈린 3열 컬러 카드로 다시 설계했습니다. 트랙별 일러스트와 수업 정보를 카드에 담고 공지를 사이에 배치합니다. 모바일은 공지 가로 스크롤과 지역 빠른 선택을 제공합니다. 세부 적용 범위와 검증은 `REFERENCE-STYLE.md`에 정리했습니다.
