# 새 화면 목업 열기

`index.html`을 내려받아 브라우저로 열면 됩니다. CSS와 JavaScript가 모두 파일에 포함돼 있어 설치·서버·로그인이 필요 없습니다.

- 첫 화면: 통계판 없이 공지사항과 지역별 트랙 카드. 공지는 포스트잇 형태이며 전체/지역 대상·중요 표시 제공.
- 전체 시간표: 날짜 × 반 교차 표. 기관별 셀 배경색과 선명한 경계선 적용. 모바일에서는 날짜별/트랙별 카드로 전환.
- 지역별: 대전·대구·부산과 기수·트랙·기관별 필터.
- 강사 이름: Lucian 상세 패널에서 공개 연락처와 안내 메모. 화살표/J/K로 이동, Esc로 닫기.
- 관리자 로그인: 실제 계정을 입력하지 않고 '관리 화면 미리보기'로 진입.
- 관리자: 공지 등록·수정·삭제와 변경 기록, 3기·4기 과정 추가, 시간표 수정, 셀 메모, 강사·과목 관리, 엑셀 미리보기와 변경 기록을 확인.
- 자료실: 파일명·과목·강사별 배치와 다운로드 흐름. 실제 교재 파일은 포함하지 않음.

모든 인물·연락처·일정·담당자·강의장·파일 크기는 가상입니다. 입력은 브라우저 메모리에만 저장되고 새로고침하면 초기화됩니다. 실제 인증·DB 연결·운영 권한·교재 업로드·다운로드는 이 목업에서 실행하지 않습니다. 예시 시간표 CSV 내려받기는 작동합니다.

원본 편집 후 단일 HTML을 다시 만들려면:

```bash
node design/mockup/build.mjs
node design/mockup/verify.mjs
```

밝은/어두운 테마, 375px 모바일, 키보드, 모션 줄이기와 주요 공개/관리자 흐름을 Chromium으로 검증했습니다. 원본 Lucian 요소는 `lucian/` 폴더에 MIT 출처와 함께 보존했습니다.

## 선택된 기본 스타일

사용자가 선택한 민트·하늘색과 둥근 흰 카드 스타일을 `index.html` 기본 목업에 적용했습니다. `index-mint.html`도 같은 내용입니다. 이전 화면은 `index-original.html`에 보존합니다. 이전안은 비교 열기용 파일이며, 현재 브라우저 검증은 새 기본 목업을 대상으로 합니다.

## 배치 변경

현재 기본 목업은 왼쪽 메뉴 대신 상단 내비게이션을 사용합니다. 첫 화면은 지역별 수업과 오른쪽 공지 영역, 모바일은 공지 가로 스크롤과 지역 선택 후 수업 카드로 구성했습니다. 전체 시간표는 본문 전체 너비를 사용합니다. 구조 변경 이전 민트 목업은 `versions/v3.html`에 보존했습니다.
